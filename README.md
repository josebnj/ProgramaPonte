# ProgramaPonte
O Programa Ponte é um treinamento realizado pelo Engenheiro de Dados Vinicius Galvão, que buscar formar novos engenheiros para atuar em demandas de clientes externos. Nesse programa iremos aprender as principais stacks e fluxo de trabalho que um engenheiro utilizada. Python, SQL, ingestão de APIs, Airflow e DBT.

Este repositório reúne os scripts, documentos e fluxos de trabalho produzidos no programa.
